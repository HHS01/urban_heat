# urban_heat
A hyperlocal urban heat risk map for informal settlements using free satellite data, with a simple dashboard or alert system.

## Project Structure

- `data/`: Contains all data files.
    - `raw/`: Original, immutable data.
    - `clean/`: Preprocessed and cleaned data.
- `scripts/`: Utility scripts for data processing and analysis.
- `artifacts/`: Generated outputs, models, and intermediate results.
- `notebooks/`: Jupyter notebooks for exploration and prototyping.
- `docs/`: Project documentation.
- `src/`: Source code for the project's core logic.
